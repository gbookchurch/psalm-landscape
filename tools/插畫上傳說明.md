# 新增插畫的方法

## 平常怎麼做

1. 把新的插畫放進 `images/psalms/` 資料夾，推送（或在 GitHub 網頁上傳）到 `main`。
2. 等一兩分鐘。GitHub 會自動重新產生 `data/images.js` 並部署網站。
3. 到 repo 的 Actions 分頁，點最新一次執行，可以看到這次新增了哪幾篇、還缺哪幾篇，以及有問題的檔案。

不需要手動改 `data/images.js`。

## 插畫檔案的規格

- 檔名以 `psalm-` 加三位數篇號開頭，後面可以接描述，例如 `psalm-040-waiting.webp`。
- 格式是 webp，正方形（現有的都是 1254×1254）。
- 背景要去乾淨（透明）。有底色的話，疊在紙底上會看到方塊。
- 同一篇只放一張。要換圖，請刪掉舊的再放新的。

不符合的檔案不會讓部署失敗，但會在 Actions 的執行結果裡列出警告。

## 第一次設定（只要做一次）

1. 把 `.github/workflows/deploy.yml` 和 `tools/build-images.mjs` 放進 repo。
   `.github` 是隱藏資料夾，用拖拉上傳時容易漏掉。也可以在 GitHub 網頁按 Add file → Create new file，
   檔名輸入 `.github/workflows/deploy.yml`，再把內容貼上。
2. 到 Settings → Pages，在 Build and deployment 的 Source 選 GitHub Actions。
3. 如果 Actions 執行時出現沒有權限寫入的錯誤，到 Settings → Actions → General，
   把 Workflow permissions 改成可讀寫。

## 想在自己電腦上先檢查

在專案根目錄執行：

    node tools/build-images.mjs

會直接更新 `data/images.js`，並列出同樣的檢查結果。
